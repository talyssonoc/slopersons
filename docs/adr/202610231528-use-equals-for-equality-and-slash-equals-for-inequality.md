# Use `=` for equality and `/=` for inequality

## Status

Accepted

## Context

Binding is spelled `=>`, so the `=` glyph is free.

## Decision

`=` is equality and `/=` is inequality.

Rejected: `==` and `!=`, which read as the C family; `<>`.

## Consequences

- There is no assignment-versus-equality confusion, since `=` is never assignment.
