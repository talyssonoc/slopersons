# Name the language slopersons, with the `.slop` extension

## Status

Accepted

## Context

The language needed a name for the command, the file extension and the documentation, settled before they were written so that nothing would need renaming.

## Decision

The language is `slopersons`, programs use the `.slop` extension, and the command is `slopersons`.

Rejected: `.slopersons` as the extension (unambiguous but long); a placeholder name to rename later.

## Consequences

- The extension appears in the CLI usage, the docs, the examples and the golden tests.
